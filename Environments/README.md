### list
• In the **[GridWorld_3x4_from-Scratch](./GridWorld_3x4_from-Scratch/)** folder, In this project, a 3×4 GridWorld environment is implemented from scratch without using Gymnasium.

• In the **[Gridworld_3x4_gymnasium](./Gridworld_3x4_gymnasium/)** folder, This project provides an interactive 3×4 "GridWorld" environment designed to help understand the fundamental concepts of reinforcement learning environments, utilizing the Gymnasium library.
